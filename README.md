# Java Vehicle Rental Management System

A Java console-based Vehicle Rental Management System built to practice OOP concepts, custom exception handling, arrays, CRUD operations, and business logic.

## Features

- Add, view, search, update, and delete vehicles
- Rent and return vehicles
- Track vehicle availability and rental status
- Calculate rental amounts with discounts based on rental duration
- Validate user input and handle exceptions

## Java Concepts Practiced

- Object-Oriented Programming (OOP)
- Classes, objects, constructors, and encapsulation
- Composition and method overloading
- Arrays and enums
- Custom exception handling
- Control flow and input validation
- CRUD operations and business logic

## Vehicle Types

- Car
- Bike
- Van

## Rental Status

- Available
- Rented

## Rental Discount Rules

| Rental Duration | Discount |
|---|---:|
| 1–2 days | 0% |
| 3–5 days | 5% |
| 6–9 days | 10% |
| 10 or more days | 15% |

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/thiru-codes/java-vehicle-rental-system.git
   ```

2. Navigate to the project directory:

   ```bash
   cd java-vehicle-rental-system
   ```

3. Compile the Java source files and run the application.
